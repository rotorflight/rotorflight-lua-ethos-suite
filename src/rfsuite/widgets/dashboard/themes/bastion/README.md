# Bastion

Bastion is a Rotorflight ETHOS dashboard theme with a technical cyan identity.

The source folder is `src/rfsuite/widgets/dashboard/themes/bastion`.
The internal ID is `bastion`, the selection is `system/bastion`, and instrument
thresholds are saved in the `dashboard.bastion` settings section.

Install the complete, matching Suite files, then restart the scripts or radio.
The dashboard and settings pages register the theme; copying this folder alone
onto an older installation does not provide that registration.
