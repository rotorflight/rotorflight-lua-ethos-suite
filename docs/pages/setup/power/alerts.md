# Alerts

Setup -> Power -> Alerts page.

## Where to find it

*Configuration* → *Setup* → *Power* → *Alerts*

Greyed out until the flight controller answers. Read-only while the model is armed.

## Settings

| Setting | What it does |
| --- | --- |
| Flight Time Alarm | Configures Flight Time Alarm. |
| Alert Type | Configures Alert Type. |
| BEC Alert Value | Configures BEC Alert Value. |
| RxBatt Alert Value | Configures RxBatt Alert Value. |

## Notes

- Changes are written to the flight controller EEPROM upon Save.
