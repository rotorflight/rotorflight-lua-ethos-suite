# Modes

Controls -> Modes. Custom editor for BOXIDS/BOXNAMES/MODE_RANGES/MODE_RANGES_EXTRA.

## Where to find it

*Configuration* → *Setup* → *Controls* → *Modes*

Greyed out until the flight controller answers. Read-only while the model is armed.

## Settings

| Setting | What it does |
| --- | --- |
| Loading mode data... | Configures Loading mode data.... |
| No modes reported by FC. | Configures No modes reported by FC.. |
| Mode | Configures Mode. |
| Auto-detect active: toggle desired AUX channel | Configures Auto-detect active: toggle desired AUX channel. |
| No ranges configured for this mode. | Configures No ranges configured for this mode.. |

## Notes

- Changes are written to the flight controller EEPROM upon Save.
