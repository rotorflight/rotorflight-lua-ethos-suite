# Adjustments

Controls -> Adjustments. Custom editor for ADJUSTMENT_RANGES.

## Where to find it

*Configuration* → *Setup* → *Controls* → *Adjustments*

Greyed out until the flight controller answers. Read-only while the model is armed.

## Settings

| Setting | What it does |
| --- | --- |
| Loading adjustment data... | Configures Loading adjustment data.... |
| Unsaved changes | Configures Unsaved changes. |
| Auto-detect active: toggle desired AUX channel | Configures Auto-detect active: toggle desired AUX channel. |
| Range | Configures Range. |
| Type | Configures Type. |
| Function | Configures Function. |
| Enable Channel | Configures Enable Channel. |
| Value Channel | Configures Value Channel. |
| Step Size | Configures Step Size. |
| Value Range | Configures Value Range. |

## Notes

- Changes are written to the flight controller EEPROM upon Save.
