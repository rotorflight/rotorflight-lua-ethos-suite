# Bypass Curve

Setup -> Governor -> Bypass Curve page.

## Where to find it

*Configuration* → *Setup* → *Governor* → *Bypass Curve*

Greyed out until the flight controller answers. Read-only while the model is armed.

## Settings

| Setting | What it does |
| --- | --- |
| *None* | This page provides status or interactive operations without persistent settings. |


## Notes

- Written to the flight controller EEPROM on Save; Rotorflight 2 applies governor settings immediately, so the save does not restart the flight controller.
