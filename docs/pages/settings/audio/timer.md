# Timer

Settings -> Audio -> Timer.

## Where to find it

*System* → *Settings* → *Audio* → *Timer*

Always available offline without an active flight controller connection. Read-only while the model is armed.

## Settings

| Setting | What it does |
| --- | --- |
| Timer audio | Configures Timer audio. |
| Elapsed alert | Configures Elapsed alert. |

## Notes

- Changes are written to the flight controller EEPROM upon Save.
