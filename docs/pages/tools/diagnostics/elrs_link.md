# ELRS Telemetry

Tools -> Diagnostics -> ELRS Telemetry page. Ported from rotorflight-lua-ethos-suite's master branch (app/modules/diagnostics/tools/elrs_telemetry.lua).

## Where to find it

*System* → *Tools* → *Diagnostics* → *ELRS Telemetry*

Greyed out until the flight controller answers. Read-only while the model is armed.

## Settings

| Setting | What it does |
| --- | --- |
| *None* | This page provides status or interactive operations without persistent settings. |


## Notes

- Changes are written to the flight controller EEPROM upon Save.
