# MSP Speed

Developer -> MSP Speed.

## Where to find it

*System* → *Tools* → *Developer* → *MSP Speed*

Greyed out until the flight controller answers. Read-only while the model is armed. Hidden until *System* → *Settings* → *Developer* mode is active.

| Setting | What it does |
