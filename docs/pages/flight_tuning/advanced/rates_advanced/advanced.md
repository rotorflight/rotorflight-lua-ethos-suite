# Advanced

Rates Advanced editor page. Loaded on demand (plain loadfile) only when the user opens Flight Tuning -> Advanced -> Rates Advanced -> Advanced -- see app/tool.lua.

## Where to find it

*Configuration* → *Flight Tuning* → *Advanced* → *Rates* → *Advanced*

Greyed out until the flight controller answers. Read-only while the model is armed.

## Settings

| Setting | What it does |
| --- | --- |
| *None* | This page provides status or interactive operations without persistent settings. |


## Notes

- Changes are written to the flight controller EEPROM upon Save.
- Parameters are scoped to the currently active Rate profile.
